Student Performance Prediction Using Machine Learning

Overview

This project is a student performance prediction prototype built using Python, machine learning, Flask, and HTML. It demonstrates how student-related data can be used to explore academic performance prediction through a web interface.

Features

- Web-based user interface
- Python-based application
- Flask integration
- Machine learning prediction prototype

Technologies Used

- Python
- Machine Learning
- Flask
- HTML
- Git and GitHub
